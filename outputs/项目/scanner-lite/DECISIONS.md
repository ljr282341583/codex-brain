# DECISIONS — scanner-lite

## 2026-11-05 用户范围与流程
- 决定：目标为个人用户的文档扫描 APK，核心功能为单页/多页扫描、PDF 导出和微信/QQ 分享；按 UI 优先流程推进。
- 理由：用户本次明确需求。
- 确认来源：当前会话用户消息。
- 取代关系：无。

## 2026-11-05 P0 技术栈与范围
- 决定：采用 Kotlin + Jetpack Compose + CameraX，最低 Android 8.0（API 26）；本期本地优先，不做账号、云同步和 OCR；首页以“开始扫描”为唯一主操作，文档列表为次入口。
- 理由：用户通过 P0 门禁确认。
- 确认来源：当前会话用户回复“过”。
- 取代关系：无。

## 2026-11-05 P1 视觉方向
- 决定：选择 A「清爽蓝图」作为完整 UI 原型和后续 Android 实现的视觉基线。
- 理由：兼顾工具可信度、中文可读性、扫描结果层次和长期使用舒适度。
- 确认来源：当前会话用户回复“选A吧”。
- 取代关系：无。

## 2026-11-06 P5 修复版
- 决定：多页拍摄保持在相机页，点击“完成（N 页）”后进入整理；照片落盘前执行方向校正、保守亮区裁边、灰度和对比度增强。
- 理由：用户指出多页拍摄需要连续完成，并指出拍摄结果仍像原始照片。
- 确认来源：当前会话用户反馈。
- 取代关系：取代 0.2.0 中拍摄后立即跳转和仅原图回显的行为。
